# Earlier builds

Three Borg Queen lists made before this repo existed, kept for reference.
`deck/decklist.txt` is the real list; don't edit these.
Reference only: being in one of these lists is not a reason to play a card.

| File | Cards | Notes |
|------|-------|-------|
| `borg1.txt` | 101 (1 over) | Oldest. 35 lands, Tezzeret, Toxic Deluge, Join the Collective, Door of Destinies, Hugh, Swiftfoot Boots |
| `borg2.txt` | 100 | Adds Urza Lord High Artificer, Sai, Padeem, Smothering Tithe, Krang, Spacecraft package, cheap counters (Dovin's Veto, An Offer You Can't Refuse, Swan Song) |
| `borg3.txt` | 101 (1 over) | Most refined. Fetch lands, Mana Drain, Force of Negation, Cyclonic Rift, Clever Concealment, Fateful Discovery, card draw off big mana values |

`Central Plexus Core` in borg1/borg3 is the Star Trek printing of **The Immortal Sun**;
the real list uses the Scryfall name. See `notes/deck-plan.md` for how the real list was built.
